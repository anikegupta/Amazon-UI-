A static Amazon homepage UI clone developed using HTML and CSS, focusing on layout design, responsiveness, and visual accuracy.

---

## 🔍 Project Overview
This project replicates the user interface of the Amazon homepage to strengthen frontend layout skills and improve understanding of real-world UI structures.

---

## 🚀 Key Features
- Amazon-inspired homepage layout
- Header, navigation bar, and product sections
- Responsive design using CSS
- Pixel-focused UI styling
